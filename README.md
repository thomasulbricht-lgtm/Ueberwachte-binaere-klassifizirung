Diese Arbeit soll schrittweise in die überwachte binäre Klassifikation einführen.
Zu Beginn werden die Vorteile des maschinellen Lernens für die Gesellschaft
dargestellt. Nachfolgend wird erläutert, was maschinelles Lernen ist und in
welchen Formen es in der Praxis Verwendung findet.
Anschließend wird das lineare Regressionsmodell erklärt und, darauf aufbauend,
das logistische Regressionsmodell. Dann folgt eine Thematisierung des Learning
Rate Scheduling. Zum Ende hin wird konzeptionell erläutert, was ein künstliches
Neuron ausmacht und wie daraus ein künstliches neuronales Netzwerk entsteht.

Zusätzlich befindet sich ein trainiertes modell im ordner   “überwachtes_binäres_klassifikationsmodell”. 
In der “überwachtes_binäres_klassifikationsmodell.py” steht, 
wie man sie testen kann und wofür die beigefügten Dateien sind.
